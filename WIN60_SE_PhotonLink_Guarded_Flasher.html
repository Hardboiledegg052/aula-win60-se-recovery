WIN 60 SE — PhotonLink Recovery

USB bootloader writer for the exact 38A6:291A / FF00:0001 interface. Uses commands recovered from AULA HUB's PhotonLink 1.6.1 SDK.

Important: This is an experimental, independently developed utility, not AULA's official flasher. It has been tested with a simulated USB device, not with a real firmware write. Writing can permanently damage the keyboard. It accepts only the exact manufacturer-hosted WIN 60 SE V0.1.0.1 file matched to the board ID; it rejects the old WIN60HE_STANDARD_RAW.bin.
